THIS IS A HAIR LAYER ONLY. Draw ONLY the hair. There must be NO head, NO face, NO eyes,

COLOUR: draw the hair in NEUTRAL GREYSCALE only — white, greys and near-black. Absolutely no

tinted later, so any colour in it would be a defect. Use value alone to describe form:
lighter where light catches the top of the mass, darker in the depth of the strands.

STYLE: clean 2D character art with a confident dark outline of even weight, large simple
shapes, and flat cel shading in a small number of value steps. Soft, friendly, readable.
No photorealism, no 3D render, no gradients-as-texture, no painterly rendering, no noise.
