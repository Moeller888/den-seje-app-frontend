## Beskrivelse

### C. Den fulde kæde i én test

`tests/isolated/laerligverse-browser.isolated.spec.mjs` kører hele kæden i en rigtig browser. Den kører i
Chromium, Firefox og WebKit, med en syntetisk elev pr. test og browser:

1. Eleven klikker i spillet: en iframe på origin `:4331` med adventure-motorens **rigtige core** og Arkivskabets uændrede scene.
2. Klikket går gennem bridge/2.
3. Testværten på origin `:4330` holder elevens session og bruger den **rigtige adapter** `LaerligTaskService`.
4. Værten kalder denne commits `get-next-question` og `process-event` på den lokale Edge Runtime.
5. `process_question_attempt` i den lokale PostgreSQL bedømmer, registrerer og belønner.
6. Dommen går tilbage gennem broen.
7. **Motorens egen graf** ændrer verdenen: skabets variant bliver `open`, og replikken `line.unlocked` udløses.

Testen bruger databasen som orakel. Den læses med den lokale service-nøgle **kun af testprocessen,
aldrig i browseren**.

**Ingen ændring af no-build-reglen.** Harnesset (`tests/isolated/laerligverse-harness/`) serverer motorens
TypeScript med typerne fjernet af Nodes indbyggede `module.stripTypeScriptTypes`. Alle 39 kildefiler
bruger kun syntaks, der kan fjernes. Import maps binder pakkerne sammen. Sider og server findes kun i
testmappen:
- de står ikke i `RUNTIME_HTML`;
- Cloudflare, `tools/cloudflare-build-static.mjs` og produktionsbuildet er ikke ændret.

Hver origin har en eksplicit tilladelsesliste:
- spillets origin får aldrig værtskode, den rigtige adapter eller testadapteren;
- ingen origin får testadapteren.

Det fastholdes af `tests/unit/laerligverse-harness.test.mjs` og af den sidste browsertest.

**Afgrænsning:**
- Spørgsmålet er et tilfældigt syntetisk spørgsmål fra elevens fag (domæne `cold_war`, klassetrin ≤ 8).
- Det er en **teknisk** demonstration, ikke Arkivskabets didaktiske opgave. Harnesset siger det i sin
  banner.
- Visningen er en minimal DOM i stedet for PixiJS. Verdenslogikken er motorens egen.

| Scenarie | Bevist mod den rigtige server |
|---|---|
| Rigtigt klik → registreret én gang, +10 XP og +5 coins, skabet åbner | ✔ |
| Forkert klik → intet udbetalt, skabet forbliver låst | ✔ |
| Dobbeltklik og samtidige afleveringer → ét `process-event`, én belønning, én reaktion i verdenen | ✔ |
| Genindlæsning før aflevering → samme serverinstans genoptages | ✔ |
| Netværksfejl før kaldet → genforsøg, én registrering | ✔ |
| Svar tabt **efter** registrering → genforsøget returnerer den **oprindelige** dom (databasen er idempotent pr. instans), én belønning | ✔ |
| Udløbet session → `session_expired` i spillet, intet registreret, ingen automatisk genafsendelse | ✔ |
| Forfalsket dom sendt ind i spillet → afvist (nonce), verdenen uændret | ✔ |
| "reward.grant" fra spillet → afvist. En anden elevs instans-id → afvist i broen; serveren svarer 403 direkte | ✔ |
| Spillet kan ikke læse værtens dokument. Spillets origin serverer ingen værts- eller adapterkode | ✔ |

**Idempotens, præcist:**
- Serveren genkender **instansen**, ikke en indsendelse: `answered=false`-CAS, og den gemte dom
  returneres.
- Det gør automatisk genafsendelse sikker for denne backend (`submitRetry: "server-idempotent"`).
- Ægte idempotens pr. indsendelse (`submission_id`, `round_no`) kræver H5. H5 er ikke anvendt i
  produktionen, og det simuleres ikke her.
- Restrisikoen er den gentagelsesrunde, der er beskrevet i D-309.

### D. Hvad mangler, før Arkivskabet er en del af Lærligs adaptive progression

| Element | Spillet i dag | Server i dag | Planlagt (D-277/LPD) |
|---|---|---|---|
| Målretning af H4 | Beder om `objectiveId` | Kun fag og domæne | `objective_id` + mål pr. emne (LP-2) |
| Introduktion → selvstændig | Skab = øvelse, skuffe = tjek | Ingen `mode`/`purpose` | `mode` i svarloggen (LP-3, #536 L1 K1) |
| Hjælp | Hints H1–H3 i testadapteren | Ingen hjælpelog | Hjælpelog på serveren; assisteret = 0 evidens (LP-5) |
| Selvforklaring | Vises kun lokalt | – | DD-2 (D-310). Ikke før LP-11 |
| Bedømmelse af kildevalg | MC via testadapter | MC kan bedømmes; kildebeskrivelser (`detail`) og tilbagevisning pr. valg findes ikke | DTO-felter + tilbagevisning pr. svarmulighed |
| Feedback efter fejl | Tilbagevisning pr. valg (testadapter) | `review_text` pr. opgave | Pr. svarmulighed |
| Svarhistorik | – | Én række pr. instans | H5 `question_attempts` |
| Overførsel | Skuffen (kontrasttilfælde) | Kan ikke målrettes | Mål + `mode=application` |
| Mastery og spaced repetition | – | **Inaktiv** | L4/L5 |
| Lærerreview | Påkrævet (materialet) | Lange svar har ingen elevvisning | LPD #16 |

**Adskillelse:**
1. Spillets funktionalitet er implementeret (D-310).
2. Serveren bedømmer i dag kun MC og kort tekst, uden mål, mode, hjælp og evidens.
3. Udvidelserne ovenfor er planlagte, ikke bygget.
4. Læringsgevinsten er en hypotese.
5. **Der er ingen dokumenteret læringseffekt.**

**Kildeanalyse kan ikke bedømmes af backend i dag**, kun som MC uden kildebeskrivelser.
