**Sidefund (ikke F8's):**

- `main`s replay-plan beskriver stadig D-237 (`20261027160000`) som ikke anvendt. Produktionens log har nu
  `20261104155040 revoke_truncate_maintain_api_roles`, så regnskabet er bagud. Det tilhører D-237-sporet.

  (`text-answer-rpc.ts`, `L1_ATTEMPT_CONTEXT`). K1 alene registrerer altså hverken Lærligverse-trinnets mode
  eller elevens hints. Det kræver L5, og indtil da kan »selvstændigt forsøg« ikke vises på serveren.

#### 3.1 Teknisk overdragelse til K1/H5-ejeren

- **Kontrakt:** `supabase/functions/process-event/text-answer-rpc.ts` (`L1_ATTEMPT_CONTEXT`, l. 114–149) sender
  `p_mode` og `p_hints_used` til `process_question_attempt_v2` og `process_text_answer_v2`. Den isolerede stak har kun
  7-parameter-versionen. PostgREST finder ingen funktion med de navngivne argumenter, og `answer-v2.ts` returnerer 500
  `{"error":"Could not process answer"}` (`UNEXPECTED_RESULT`).
- **Reproduktion:** `gh workflow run isolated-e2e.yml --ref feat/laerligverse-f7-evidens` (den isolerede stak, ikke
  produktion). Se `tests/isolated/learning-sequence.isolated.spec.mjs`, »D-341 characterization«.
- **Forventet:** en H5-indsendelse (`round_no` + `submission_id`) giver 200, én attempt og én belønning.
- **Faktisk:** 500, ingen attempt, ingen belønning, og runden er stadig åben.
- **Mulige rettelser (ejerens valg):**
  - (a) Flyt K1 til `REPO_AHEAD_OF_PRODUCTION`. Det er ejerbeslutningen fra 2026-10-28 (»where the repository's own
    code depends on such a migration, CI applies the real migration file«), og den passer på netop dette tilfælde.
  - (b) Lad `process-event` kun sende `p_mode`/`p_hints_used`, når skemaet har dem.
- **Når det er rettet:** `k1-probe.mjs` slår om, og de 10 markerede tests kører som almindelige tests og skal
  være grønne uden ændrede assertions. Karakteriseringstesten springes over.
- **Hvad hullet blokerer i F8:** generalprøven mod den rigtige server. Den er derfor kørt mod den rene
  sekvensfunktion. Desuden enhver påstand om, at en H5-registrering virker i testmiljøet i dag.
